# Participation during the MVP

We accept issues and suggestions during the MVP. We do not accept external code
contributions or code pull requests at this stage. The contribution process
will be described separately if external code is accepted later.

For a bug report, include the software version or commit, installation method,
expected behavior, actual behavior and a minimal reproduction using generic
hosts and paths. Remove credentials, command output containing sensitive data,
private domains and customer identifiers. For a suggestion, describe the
operational problem and the action or policy behavior you need.

Report vulnerabilities through the private process in [SECURITY.md](SECURITY.md).
Do not include exploit details in public issues.

Local maintainer checks are `make build` and `make test lint`. Documentation
checks are described in [website/README.md](website/README.md).
